# TypeSimulator v1.2.0

本版本修复打字速度设置，并新增剪贴板直接输入和启动等待。

## 更新内容

- #1：修复取消“随机延迟”后设置未生效；速度范围扩展为 10–6000 CPM，步进 10。修复高速度下受定时回调频率限制的问题，卡顿后每次最多补发 4 个到期字符。
- #2：使用 SendInput Unicode 事件替代 SendKeys，改善中英文混输；键盘钩子过滤模拟事件，避免递归映射，并修复最后一个映射字符漏出原始按键的问题。
- #3：新增“启动时直接读取剪贴板”。在目标窗口按 Ctrl+Alt+T 启动，每次新任务读取最新文本；恢复时保留原快照，空剪贴板不使用旧文本。
- #4：新增 0–60 秒启动等待，默认 3 秒。倒计时可暂停、恢复、停止或通过 F12 重置。
- 新增本地 SDK 安装、构建和测试脚本，运行目标保持 .NET Framework 4.8。

## 下载与运行

推荐下载 `TypeSimulator-v1.2.0-win.zip`，完整解压后运行 `TypeSimulator.exe`。
也提供单独 EXE 下载。需要 Windows 10/11 和 .NET Framework 4.8。
使用 `SHA256SUMS.txt` 检查下载文件的 SHA-256。

## 验证范围

Windows x64 上 Release 编译通过，0 警告、0 错误，59 项自动化检查通过。
关闭随机延迟后，10、50、400、1200、3000、6000 CPM 六档引擎测试误差均低于 1%，
测试文本没有遗漏、重复或顺序变化。覆盖等待、暂停、停止、剪贴板快照、窗口初始化和高速卡顿恢复。

这些计时结果使用内存输出器，**不代表所有目标软件都能以相同速度接收文本**。
搜狗输入法和具体目标应用尚未人工实测。Unicode 事件修复已提供；若仍出现候选框或焦点问题，
请重新打开 #2 并提供输入法版本、目标应用及复现文本。
随机延迟开启时，标点停顿会降低平均 CPM。目标程序繁忙时也可能降速。
本版提供便携程序，不包含 ClickOnce 安装包。

## 源码开发

在仓库根目录运行 `./scripts/setup.ps1` 配置环境，或运行 `./scripts/build.ps1 -Test` 构建并测试。
详细步骤和兼容性验收见仓库中的 `DEVELOPMENT.md`。
